# SplitEasy frontend

React + Vite SPA for [SplitEasy](../README.md) — see the root README for the full write-up, local setup,
and deployment instructions. This file only covers commands specific to this directory.

```bash
npm install
npm run dev       # dev server with HMR, http://localhost:5173
npm run test       # Vitest suite
npm run build       # type-checks and builds to dist/
npm run lint         # oxlint
```
