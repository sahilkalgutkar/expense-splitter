# SplitEasy backend

NestJS API for [SplitEasy](../README.md) — see the root README for the full write-up, local setup, and
deployment instructions. This file only covers commands specific to this directory.

```bash
npm install
npm run start:dev     # dev server with hot reload, http://localhost:3000/api
npm test               # unit tests
npm run test:e2e       # e2e suite against a real Postgres database
npm run build           # compiles to dist/
```
